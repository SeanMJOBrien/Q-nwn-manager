Ingest a module

1. Start the console

The upload / ingest actions below talk to the console, so it needs to be running first. From the repository root, run:

bin/nwn-manager console

(or just nwn-manager console if it is on your PATH). It prints a line like Serving on http://127.0.0.1:8341/. Leave it running, then reload this page.

● Console is running. Open the full console  

Ingesting creates a new project from a Neverwinter Nights .mod (or .erf) that you can then edit, wiki, build, and download from the console.
